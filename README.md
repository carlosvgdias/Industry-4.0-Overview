# Industry 4.0 – Power BI Dashboard

This repository contains an **Industry 4.0 dashboard project** developed in Power BI, focusing on asset condition monitoring, failure analysis and simulated operational KPIs.

## Dashboard Structure

### Page 1 – Executive Overview
- Total failures and fault rate
- Failure trends over time
- Failures by plant and asset type

### Page 2 – Asset Condition Analysis
- Vibration and temperature behavior (Normal vs Fault)
- Condition degradation by asset type
- Scatter analysis for predictive maintenance insights

### Page 3 – Operational KPIs (Simulated)
- Availability
- OEE
- MTBF / MTTR

> ⚠️ Note: Operational KPIs are simulated and clearly identified as such.  
> They are included for analytical demonstration and dashboard completeness.

## Key Concepts
- Data modeling with a proper calendar table
- Clear separation between real and simulated metrics
- Executive and technical storytelling
- Industrial-tech visual standards

## Tools
- Power BI
- DAX
- Data modeling (star schema)
- Simulated industrial datasets
